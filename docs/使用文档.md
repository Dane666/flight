# 机票监控使用文档

## 1. 版本说明

当前版本仅使用 **Trip.com 网页抓取**（`trip_scrape`），不依赖任何付费 API。
已移除 Google Flights (SerpApi)、Kiwi、Amadeus 等 provider，因为没有充值额度。

核心功能：
- 手工搜索：指定出发地/目的地/日期，滑动窗口自动生成往返组合
- 多目的地对比：同一次搜索对比 PQC 和泰国多城市最优价
- 两阶段抓取：先快速扫价，再对最优候选补抓详情
- Bark 推送：结果自动推送到 iPhone
- GitHub Actions 定时运行：自动执行中秋/国庆/春节多方案搜索

## 3. 手工搜索（推荐日常使用）

### 3.1 基本用法

```bash
python main.py search \
  --origin HKG \
  --destination PQC \
  --depart-date 2026-09-25 \
  --return-date 2026-10-07 \
  --window-days 2 \
  --label "中秋国庆"
```

### 3.2 参数说明

| 参数 | 必填 | 说明 |
|------|------|------|
| `--origin` | 是 | 出发地 IATA 码，如 HKG |
| `--destination` | 是 | 主目的地 IATA 码，如 PQC |
| `--depart-date` | 是 | 参考出发日期 YYYY-MM-DD |
| `--return-date` | 是 | 参考返程日期 YYYY-MM-DD |
| `--window-days` | 否 | 滑动窗口天数，默认 2 |
| `--label` | 否 | 搜索标签，出现在推送标题 |
| `--no-thailand` | 否 | 仅搜主目的地，不加泰国 |
| `--config` | 否 | 配置文件路径，默认 config.yaml |

### 3.3 默认行为

不指定 `--no-thailand` 时，同时搜索：
- `--destination` 指定的目的地
- 配置文件中 `thailand_destinations` 列表的所有目的地

输出每个目的地的最优价格，按价格升序排列，最低价前标记 ★。

### 3.4 推送输出示例

```
【中秋国庆桥-请假3天】
窗口: 2026-09-23 ~ 2026-10-09

★ HKG -> PQC
  日期: 2026-09-24 / 2026-09-28 (4天)
  去程: 08:30 -> 10:15
  返程: 19:20 -> 21:05
  价格: 1840.00 CNY (原价 266.00 USD)
  航班 CX731 | 航司 Cathay Pacific | 直飞

· HKG -> BKK
  日期: 2026-09-25 / 2026-09-29 (4天)
  去程: 09:15 -> 11:30
  返程: 17:45 -> 20:10
  价格: 2100.00 CNY (原价 304.00 USD)
  航班 TG601 | 航司 Thai Airways | 直飞
```

## 4. 配置文件

### 4.1 生成默认配置

```bash
python main.py init-config --force
```

### 4.2 核心配置项

```yaml
provider: trip_scrape           # 数据源
currency: CNY                    # 输出币种
trip_scrape_timeout_seconds: 60  # 抓取超时
alert_threshold: 2200            # 告警价格阈值
alert_cooldown_minutes: 180      # 告警冷却时间
interval_minutes: 30             # 持续监控间隔
origins: [HKG]                   # 出发地列表
destination: PQC                 # 主目的地
thailand_destinations: [BKK]     # 泰国对比目的地
bark_device_key: "..."           # Bark 设备密钥
notifier: bark                   # 通知方式
```

## 6. GitHub Actions 定时任务

工作流 `.github/workflows/nightly-monitor.yml` 自动执行 5 组搜索：

| 搜索任务 | 日期范围 | 说明 |
|---------|---------|------|
| 中秋 | 09-24 ~ 09-28 | 中秋节前后一天，灵活出发 |
| 国庆 | 10-01 ~ 10-08 | 国庆假期前后一天 |
| 中秋国庆桥 | 09-23 ~ 10-09 | 请假 3 天连休方案 |
| 春节 | 02-13 ~ 02-24 | 春节前后两天 |
| 春节特价 | 02-05 ~ 02-12 | 节前特价窗口 |

每组搜索同时输出 PQC 和泰国多城市最低价对比。

**所需 Secret：**
- `BARK_DEVICE_KEY`

## 7. 输出字段解释

```
[中秋] HKG->PQC 2026-09-24/2026-09-28 (4天) go=08:30->10:15 back=19:20->21:05 PRICE=1840.00 CNY (src=266.00 USD) flight=CX731 airline=Cathay Pacific stop= direct=Y
```

| 字段 | 说明 |
|------|------|
| `go=去程起飞->到达` | 去程时间 |
| `back=返程起飞->到达` | 返程时间 |
| `PRICE` | 换算后目标币种价格 |
| `src` | 源站原始价格与币种 |
| `flight` | 航班号 |
| `airline` | 承运航司 |
| `stop` | 中转信息 |
| `direct` | Y=直飞 N=中转 |

## 8. 常见问题

### 8.1 抓取偶发失败

表现：`[WARN] Trip 页面未解析到价格 ...`

处理：
- 重试运行（内置最多 3 次重试）
- 调大 `trip_scrape_timeout_seconds`
- 等待网络恢复后再跑

### 8.2 没有航班号

部分页面不会暴露航班号，当前策略会尝试多种方式提取；若仍未获取则省略。

### 8.3 先验证流程

可临时切换 mock 模式：

```bash
# 编辑 config.yaml
provider: mock
python main.py search --origin HKG --destination PQC --depart-date 2026-06-19 --return-date 2026-06-22
```
